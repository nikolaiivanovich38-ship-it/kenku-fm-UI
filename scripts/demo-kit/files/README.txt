Lyre {{version}} demo kit

This folder lets you try every part of Lyre without your own music library. Music has four short pieces, Ambience two background loops, Effects five sound effects, and Local soundboard a small web page that plays its own sounds. Everything in it was made for Lyre by the Lyre project and may be shared freely (GPL-3.0, like Lyre itself).

To use it, unzip the folder somewhere permanent, for example Documents, because Lyre plays the files from where they are. In Lyre, drag the Music folder onto the Playlists page to make a playlist, and drag the Effects folder (and Ambience, if you like) onto the Soundboards page to make soundboards. To try opening a file from your computer, open a new tab, type the full path of Local soundboard\soundboard.html into the address bar (for example C:\Users\you\Documents\Lyre-demo-kit\Local soundboard\soundboard.html, or paste it from Explorer's "Copy as path"), press Enter and choose Open. The Extra formats folder is for checking the new Lyre tab: an AIFF copy of an effect, which Lyre plays through a converted copy, and a text file whose name ends in .mp3, which Lyre should refuse as not audio. Every sound has a title, artist and album in its file tags, which the Lyre tab's Library shows.

The step-by-step demo and test script is the "Lyre {{version}}: demo and test script" guide that came with this release.
