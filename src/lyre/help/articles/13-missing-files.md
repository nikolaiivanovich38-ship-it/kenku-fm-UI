When you move or rename audio files, Lyre can no longer find them. Their rows in the Library say **Missing**, and **Filters** › **Missing** lists them.

1. Library › **⋯** beside **Add tracks** › **Find missing files…**.
2. **Look in a folder**: type a folder, choose one, or drop it on the page.
3. Lyre matches files by name and size. A match with the same name and size is ticked. The same name with another size is not ticked: Preview it first.
4. Press **Relink** (it says how many files). **Undo** puts them back if a match was wrong.
